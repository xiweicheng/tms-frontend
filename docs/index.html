核心特性

开箱即用的团队协作能力，覆盖沟通、知识与任务协作

💬

实时团队沟通

基于 SockJS + STOMP 的 WebSocket 实时通信，支持私聊、频道群聊、@ 提及、消息回复、消息搜索与过滤、文件附件、富文本与 Markdown 输入。

📚

博文知识库

多空间、多层级目录的博文管理，支持 Markdown / 富文本 / 表格 / 思维导图 / 白板 / 流程图六种编辑器，版本历史与 diff 对比、评论与分享。

🗂️

看板任务管理

频道内的看板式任务流（待规划 / 待处理 / 进行中 / 已完成 / 已验收），支持任务标签、任务讨论、跨频道任务面板、拖拽排序。

📅

日程与甘特图

FullCalendar 日程视图、自定义提前提醒、WebSocket 日程变更推送、甘特图编辑，让团队节奏一目了然。

📱

全端响应式

viewport 锁定缩放、移动端布局自动切换、侧边栏折叠、触摸友好的交互，一套代码覆盖桌面与移动端。

🔔

多通道通知

桌面通知（push.js）、声音提醒（alert.mp3/ogg）、Toastr 气泡、未读消息角标，关键消息不遗漏。

🔌

事件总线架构

基于 Aurelia EventAggregator 的全局事件总线，统一编排 90+ 事件名，组件解耦清晰，扩展容易。

事件总线与通信

统一的组件解耦与 iframe 编辑器通信协议

// 1. 事件总线：发布 / 订阅（全局变量 ea 来自 Aurelia EventAggregator） this.subscribe = ea.subscribe(nsCons.EVENT_BLOG_CHANGED, (payload) => { if (payload.action === 'updated') { _.extend(this.blog, payload.blog); } }); // 2. iframe 编辑器 postMessage 通信协议 // 子窗口 → 父窗口 window.parent.postMessage({ action: 'created' | 'updated' | 'isUpdated', source: 'blog' | 'comment', data: {} }, window.location.origin); // 3. 自适应轮询：6s 起步，无数据递增到 5min 上限 poll.start((reset, stop) => { return fetchLatest().then(data => { if (data.hasNew) reset(); // 有新数据 → 恢复 6s }); });

快速开始

三步启动开发环境

安装 aurelia-cli

全局安装 Aurelia 命令行工具

# 全局安装 aurelia-cli npm install aurelia-cli -g

安装工程依赖

在项目根目录执行依赖安装

# 进入工程目录后 npm install # 或使用 pnpm pnpm install

启动开发模式

默认带 watch + browser-sync，访问 http://localhost:9000

# 开发模式 au run --watch # 生产构建 au run build --env prod

部署到后端

生产构建后，将工程内容（排除 node_modules）复制到 TMS 后端

# 1. 生产构建 au run build --env prod # 2. 复制到后端工程（排除 node_modules） # 目标路径：tms/src/main/resources/static/page rsync -av --exclude='node_modules' \ --exclude='.git' \ ./ tms/src/main/resources/static/page/
